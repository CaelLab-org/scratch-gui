# XMUER Forum (XF)

The discussion forum of the CaelLab family. Site: <https://forum.xmuer.online/>

## Facts

- Name: XMUER Forum, also written XF.
- Introduction on the site: 「以轻舟之姿探索未知之境。以编程为核心锚点，汇聚四方技术同好，畅聊创作思路与技术难题。」
  So: programming is the anchor, and it is for trading ideas and solving technical problems together.
- Copyright line: `© 2025-Present XMUER by 虚舟实验室 (CaelLab)`
- Footer links to the rest of the family: CaelLabGameTS, XCC, 轻之舟百科, CaelLabID, CaelLabMinecraft.
- Policy links in the footer: 虚舟实验室隐私权, 隐私政策, 服务协议, 社区守则. There is also a 「发现不妥内容？」
  address for reporting bad content.
- There is an Android client.
- Pages are rendered by JavaScript, so anything fetched as plain HTML can show only a 「正在加载…」 placeholder.

## When to send the user here

- A bug that is about the **editor's own product behaviour** (not about this AI assistant) belongs in the
  editor's own feedback thread rather than a private message. The editor's menu bar links to
  <https://forum.xmuer.online/t/problem> as 「XMUER Coding Engine 反馈」.
- A question that needs a human answer, or a discussion the user wants other people to see, belongs on the
  forum too.
- Do **not** tell the user to post something for you. You are the one who answers here; the forum is for
  things you cannot do (reporting a bug you cannot reproduce, asking the community's opinion).

The forum's own rules live at 社区守则 in its footer — read them there rather than reciting them from memory.
