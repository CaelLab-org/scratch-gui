# Detailed doc: every CaelLab project

Read this when the user asks what else the team makes, what a CaelLab/XMUER site is for, or where to find
something that this editor does not do. The grouping below is the official site's own.

## Community

- **轻之舟百科** — <https://130.wiki/> — the encyclopedia CaelLab creates and operates.
- **XMUER Forum (XF)** — <https://forum.xmuer.online/> — the discussion forum. Detailed doc: `xce_fastdocs_xf`.
- **XMUER Coding Community (XCC)** — <https://coding.xmuer.online/> — where people share finished
  projects, under a team section called 「共创世界」. Detailed doc: `xce_fastdocs_xcc`.

## Tools

- **XMUER Coding Engine (XCE)** — <https://engine.xmuer.online/> — the editor you are running inside.
  Detailed doc: `xce_fastdocs_engine`.
  - **XCE Desktop** — <https://engine.xmuer.online/desktop/> — the same editor packaged as a Windows
    application, so projects run offline and the browser cannot throttle or discard a tab. Same features as
    the web version, plus native-desktop performance. The download page is the `/desktop/` page on the
    editor's own domain.
- **XMUER Coding Packager** — <https://packager.xmuer.online/> — 「Convert Scratch projects to HTML, EXE,
  and more」: takes a project and produces a runnable HTML page or a Windows executable. This is the step to
  point a user at when they want a file that runs without Scratch — the editor itself only saves `.sb3`.
- **CaelLab Search** — <https://caellab.click/> — the team's own web search, over its own index. It is not a
  third-party engine in disguise: the `xce_search` tool in this editor is powered by it, and search results
  you show the user should credit it as the source.
- **SiteLop** — <https://site.caellab.com/> — 「网站信息查询工具」 / domain intelligence: WHOIS (registrar,
  dates, status), DNS and IP lookup (IP, nameservers, geolocation, ISP) and a Minecraft Java server monitor.
  Free, no sign-up, answers served from a cache.

## Games — CaelLabGameTS

**CaelLabGameTS** — <https://gamets.caellab.com/> — is CaelLab's games arm, launched **2026-05-07** and
described on its own site as 「虚舟实验室旗下独立游戏开发与运营团队」 (an independent game development and
operations team under CaelLab). Its titles live under `gamets.caellab.com`:

- **GoodPlanCraftLauncher (GPCL)** — <https://gamets.caellab.com/gpcl/> — a Minecraft launcher: lightweight,
  offline play, automatic version management, open source. In the user's local projects it is the folder
  `GoodPlanCraftLauncher`, shortened to GPCL.
- **AreYouOK?** — <https://gamets.caellab.com/areyouok/> — a pixel-art platform jumper for Windows, built to
  start instantly.
- **The Endless Corridor（无尽长廊）** — <https://gamets.caellab.com/the-endless-corridor/> — a horror
  adventure / puzzle game still in development, by 倒反天狗 (the team member who works in Godot).
- **CaelLabMinecraft** — <https://minecraft.caellab.com/> — the team's Minecraft server: a small survival
  world on Paper. Players sign in with CaelLabID, bind a game name once, then connect with the key the site
  gives them. The site also has player pages, a gallery and guides, and lists the team's own plugins.

## Creative

- **TimeNotes · 时光笔记** — <https://www.caellab.com/2026/timenotes/> — a digital journal (手账) with
  real-time multi-person collaboration.
- **XiaomiMiMo** — <https://www.caellab.com/2025/xiaomimimo/> — a web-packaged version of Xiaomi's MiMo.

## Using this when you answer

- "Where do I share what I made?" → XCC. "I want an .exe / a web page out of my project" → the Packager.
  "This editor has a bug" → the editor's own feedback thread on the forum, not a private message.
- Do not invent features, prices, user numbers or release dates for any of these. If the user needs current
  details, open the site and read it.
