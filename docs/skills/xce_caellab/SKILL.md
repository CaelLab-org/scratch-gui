# CaelLab (虚舟实验室)

CaelLab is the team behind **every** XMUER site, including the editor you are running inside.
It is not a single person with a blog: when you write about it, write about the team and its projects,
never as a "personal website" of an individual.

## Facts

- Name: 虚舟实验室 (CaelLab). Website: <https://www.caellab.com/>
- Slogan: 「探未来之境 · 载无界新生」
- Self-description: 专注于编程领域创新的青少年编程团队（a youth programming team focused on innovation in programming）
- Founded: 2025-07-05, when the domain `xuzhoulab.cn` was registered and work started on the CCW platform.
- Since 2025-08-13 it operates independently; it is **no longer** in any partnership with 「果园编程工作室」.
  Never describe the two as partners.

## Projects

Organised the way the official site groups them:

- **Community**: 轻之舟百科 (130.wiki, an encyclopedia), XMUER Forum, XMUER Coding Community
- **Tools**: XMUER Coding Packager, CaelLab Search, SiteLop, **XMUER Coding Engine** (this editor)
- **Games**: a Minecraft server, GoodPlanCraftLauncher, AreYouOK?
- **Creative**: TimeNotes · 时光笔记, XiaomiMiMo

## Federated identity and policy sites

- **CaelLabID** — <https://id.caellab.com/> — the shared login service. Sites that need accounts sign in
  through it with OAuth 2.0 rather than building their own accounts.
- Policy and public documents live on **policy.caellab.org** (privacy, terms, integrity, human rights).
- Contact hub: <https://caellab.org/who-we-are/contact/>
- Legal/registration notice shown in footers: 舟ICP备 97257623号 (创意型作品) on caellab.com,
  舟ICP备 20250705号 on caellab.org, and other numbers on the individual sites.
- Footer copyright line: `© 2025-Present 虚舟实验室 (CaelLab). All rights reserved.`
- Licensing of the sites themselves: code under the CaelLab BY-SA Code License, text under CC BY-SA 4.0.

## Contacting the team

Give the user an email link, never "go find the site owner". The contact page lists a general address plus
per-project ones（轻之舟百科 / 论坛 / 编程社区 / CaelLab Search）and additional addresses for rights,
donations and integrity questions. Read the current list at
<https://caellab.org/who-we-are/contact/> and link the user there rather than reciting an address from memory
— addresses on that page are deliberately obfuscated against scrapers and may change.

Public social accounts (from the official site): GitHub `caellab-com`, Bilibili `1199120693`,
YouTube `@CaelLab`, XCC team `team/caellab`, Kuaishou `3xgrwi2jsy45yza`.

## How to talk about it

- 中文回答，用「虚舟实验室（CaelLab）」，不要写成个人站长口吻。
- Do not invent founding dates, staff, funding, or partnerships. If the user asks something not listed here,
  say you are not sure and point at <https://www.caellab.com/>.
- Do not write statements of the form 「符合中国 xx 法律」— these are not China-localised sites.
