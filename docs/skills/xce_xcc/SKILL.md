# XMUER Coding Community (XCC)

The place in the CaelLab family where people **share finished projects**. Site: <https://coding.xmuer.online/>

## Facts

- Name: XMUER Coding Community, shortened to **XCC**.
- Pitch: 「分享你的 Scratch 作品，学习编程，与创作者交流」
- What is on it: a recommended-projects feed of project cards (title, author, a duration/size figure), and a
  team section called 「共创世界」.
- Navigation: 首页 / 团队 / 纯享空间, plus 登录 and 开始创作. There is a theme switcher (follow system / light /
  dark / tech-blue).
- Footer: `© 2026 XMUER Coding Community`, 舟ICP备 67114514号, a privacy policy link, an email contact,
  and 「Powered By 虚舟实验室 · CaelLab Project」.

## What this means for the user

When somebody finishes something in this editor and asks "now what?", XCC is the answer: they can publish the
project there and share it. Note that publishing is the user's action on that site — you have no tool that
uploads anything, and this editor has no account system of its own.

Signing in across CaelLab sites goes through **CaelLabID** (<https://id.caellab.com/>), the shared identity
service, not through a per-site account.

Do not invent numbers (how many projects, how many users, ranking rules) — if the user wants that, open the
site and read it rather than guessing.
