XCE Agent

编辑器内置的 AI 助手。你用一句话说要什么，它把积木真的写进项目里 —— 写脚本、绘制造型、 读懂并运行你的作品、看结果对不对，而不是只给一段建议让你自己动手。

打开编辑器

内置在 XMUER Coding Engine 里 · 与网页版、桌面版是同一个助手 · 查看源码

它能做什么

写和改积木

你说要什么效果，它把对应的 Scratch 积木直接加到角色上；要改现有脚本， 它按积木的位置替换，不动你没提到的部分。

画造型

用代码画一个 SVG 造型，或者给一个图片网址让角色换上。 造型、角色都能新建和删除。

读懂你的项目

列出所有角色、读出每个角色的积木、看舞台截图 —— 它先弄清你现在有什么， 再动手改。

跑一遍再交给你

点绿旗运行、读变量和角色的位置，确认结果是你要的那个； 不对就接着调。

联网查资料

桌面版里它能直接读公开网页（5 秒超时、最长 20KB）， 需要查库名、语法或现成做法时用得上。

记住你的偏好

项目级的笔记和长期记忆：你交代过的风格、约定，下次打开还在， 不用每次重讲。

怎么用

  1. 打开 engine.xmuer.online，右上角进编辑器（桌面版则直接打开应用）。
  2. 进入编辑器后，XCE Agent 就停靠在左侧、和积木区并排；标题栏能收起、也能全屏。
  3. 用中文或英文说你想要的效果，例如「做个数到 10 的计数器」，它会直接改项目。
  4. 改完它跑一遍、把结果给你看；不满意就接着说，随时可以撤销。

XCE Agent 用你自己的模型密钥：在设置页里添加，支持 OpenAI 兼容与 Anthropic 两家协议， 密钥只存在你自己的浏览器里。
