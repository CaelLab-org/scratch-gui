4.10.0

2026-11-26

外置 AI 现在能读到编辑器自己的说明书，也能直接加声音；顺手修掉 AI 写完积木偶尔弹出的「变量名」确认框，并把设置页和面板的交互重新打磨了一遍。

外置 AI

  • 外部 AI 现在会收到编辑器自己的系统提示词：项目规矩、工具用法、积木文本格式、你写的自定义提示词和记忆索引。MCP 客户端在初始化时自动拿到；HTTP 入口新增 GET /v1/instructions。
  • 新增工具 xce_read_instructions 和 MCP prompt xce_instructions：客户端没把说明转给模型时，随时能重新读一遍。
  • 外置 AI 现在能真的看到舞台和造型截图。以前外置通道被当成纯文本模型，图片会被丢掉。
  • 命令行工具新增 xce instructions（0.2.0）；xce-mcp 升到 1.3.0。设置 → 外部接入里的说明书也跟着更新了。

声音素材

  • Agent 新增 xce_add_sound / xce_delete_sound：支持 mp3 / wav，可以给网址也可以直接给 base64；单个文件上限 10MB，重名会自动加后缀。
  • 角色清单现在会列出每个角色的声音名，Agent 写「播放声音」积木时不会再瞎猜。
  • 外部接入新增 POST /v1/assets：几 MB 的音频直接传原始字节，拿到 assetId 再交给 xce_add_sound。素材只在内存里留 30 分钟，最多 8 份。

修复

  • AI 写完积木排版时，会被开发者工具里的「整理积木+」接管，100ms 后弹一个原生确认框问要不要删没用到的局部变量；中文文案当时是空的，正文只剩一个变量名（就是那个「测试血量」弹窗），点确定会真删变量。现在 AI 排版只做布局，不触发删除确认。
  • 用户自己点「整理积木+」时，确认框也会说清楚在问什么，不再只剩一串变量名。
  • 外置通道的 xce_read_stage / xce_read_costume 不会再永远返回「当前模型看不了图」——现在会按图片发出去。

界面与动效

  • 外部接入的开关换成真正的 switch：左边一个状态点，开着是绿的并轻轻呼吸；下面直接写监听范围和端口。说明书默认折叠，想看全文再展开，不再一屏几千字。
  • 复制按钮点完变绿并轻弹一下；地址、密钥、说明书都在按下的位置给反馈。
  • 设置分区列表、设置页、历史、工具行按同一套节奏入场：180–240ms、最多从 6px 落下，列表错开 30–45ms，不拖尾。
  • 所有按钮补了键盘焦点圈（2px），按压下沉 1px；系统开了「减少动态效果」时全部动画关闭。
  • 确认对话框入场改成 180ms 淡入 + 2px 下沉 + 很轻的背景模糊，跟虚舟其他项目的确认框一致。
  • 桌面版下载页和更新日志：首屏与卡片错开入场，卡片悬停抬 1px，键盘焦点可见。

4.9.0

2026-11-26

AI Agent 的工具箱大扩容，新增「每次确认」权限档位；并修掉变量积木「落地就是坏」的一批问题。

Agent 新工具

  • 新增「创建变量 / 创建列表」：Agent 能直接建变量和列表，默认所有角色可见，也可以指定成某个角色的私有变量，支持初始值。
  • 新增「自定义积木（我的积木）」：Agent 能定义带参数的积木，支持布尔参数（六边形）和「运行时不刷新屏幕」，建完会直接告诉你调用写法。
  • 新增「添加扩展」：Agent 能自己加载画笔、音乐这类内置扩展——以前写到一半要你手动去左下角加。
  • 角色清单里会带上自定义积木名；读积木时 define 定义也能原样读回来。

权限档位（新）

  • 设置 → 权限新增档位开关：默认「完全访问」不打扰；切到「每次确认」后，每个会改项目的操作（写积木、删脚本、建变量、加载扩展……）都先弹一张卡片，写明这一步会动什么，允许才执行。
  • 只读操作（读积木、看状态、截图）不弹窗——一口气查十次资料不会被拦十次。

修复

  • Agent 写积木时变量少写那个 v（写成 [血量] 而不是 [血量 v]）会落地成空下拉、变量也没创建——现在一律按变量槽处理并自动建变量。
  • 变量和列表同名时会建出两个同名的「背包」，现在整体拒绝并说明。
  • 调用没定义的自定义积木会生成一块点了没反应的死积木，现在整体拒绝并提示先定义。
  • 「停止 [全部脚本]」的下拉以前是空的，现在能写对。

4.8.1

2026-11-26

外部接入多了一份可以直接粘给 AI 的说明书，粘一次就能把编辑器交给对方的 agent 用。

外部接入

  • 设置 → 外部接入里新增「粘给 AI 的一段话」：地址、密钥、怎么列工具、怎么调用、什么不能做，按节写成一份说明书，整段复制即可。
  • 说明书里同时给了「命令行」和「MCP」两条接法 —— 客户端支持 MCP 就把工具挂进它自己的列表，不支持就照着命令敲，用户只需要粘一次。
  • 四种语言：简中 / 繁中 / 英 / 日，默认跟着编辑器语言走，认不出来用英文，面板里也能手动切，选过的会记住。
  • 提示词里的地址默认用局域网那条（服务本来监听 0.0.0.0），本机和别的机器都能连；换机器时不用改。
  • 新增「监听范围」：默认对局域网开，也可以切成「仅本机」—— 只绑 127.0.0.1，别的机器再怎么试也连不上。切换会立刻重开监听，密钥不变。
  • 原来的「贴给 Claude Code」「贴给别的 AI」两段合并成「说明书」+「MCP 配置」两块，页面短了一段。

自动更新（新，仅桌面版）

  • 桌面版会自己查新版：启动十几秒后在后台读一次下载站上的清单，有新版就在右上角「更多」上点一个小圆点，菜单里直接写「更新到 4.9.0」。
  • 设置 → 关于与更新：看当前版本、检查更新、下载（带进度）、安装并重启。
  • 安装包下完先算一遍 sha256，对不上就丢掉重来；下好的包留在本地，下次点安装不用再下一遍。
  • 安装是静默的：当前窗口关掉，装完自动把新版打开；项目和设置都在原处，不会被覆盖。
  • 离线、或者服务器一时连不上，后台检查静默跳过，不弹任何东西。

安装程序

  • 不再弹语言选择器：直接跟系统语言走，认不出来就用英文。
  • 许可协议从「必须点同意」改成安装前的提示页——隐私政策和 AGPL-3.0 的说明在同一页里，看完直接下一步。

  • 入口只有健康检查、工具清单、调用三个路由，没有文件系统、没有 shell；开关默认关着。

4.3.3

2026-10-23

这一版让作品文件可以直接双击打开，默认的思考强度调低了，许可证换成 AGPL-3.0。

双击作品直接打开

  • 安装时会把 .sb3 和 .xce 与本程序关联（那一步可以取消）。双击作品就在编辑器里打开，Ctrl+S 存回原文件。

AI 终端

  • 默认思考强度改成「低」，新对话更快、更省；想让它多想一会儿，在输入区或设置里切回「高 / 最高」。
  • 回复下方那行 token 用量去掉了。想看本会话累计的输入 / 命中 / 输出，把鼠标移到输入框旁的上下文百分比上。
  • 修正会话累计的缓存命中率：DeepSeek 等把命中数放在详情字段里的供应商，不会再显示「缓存未报」。

其他

  • 移除自动保存 / 刷新恢复：它会在打开 URL 项目时用旧快照覆盖刚加载的项目，表现为编辑器空白或一直加载不出来。
  • 许可证改为 AGPL-3.0-only（GPL-3.0 与它兼容），源码文件统一加上项目和许可说明头。

4.3.2

2026-10-12

这一版给编辑器里的 AI 助手起了名字 —— XCE Agent，并修掉一个会让积木「看着写好了、其实永远不触发」的 bug；桌面版的安装器也换成了 Inno Setup。

AI 助手有了名字：XCE Agent

  • 首页功能卡片、页脚、桌面通知和编辑器里的 AI 面板，都改用它的名字 XCE Agent（简中、繁中、英文一致）。
  • 新增一页介绍 /xce-agent/：它能做什么、怎么用、源码在哪。
  • 被问到「你是谁」时，它回答自己叫 XCE Agent、是 XMUER Coding Engine 的助手。

修掉「写入成功却永远不触发」的积木

  • 下拉菜单的取值改成按积木分别查：以前同一段显示文字先扫到哪个扩展、就用哪个扩展的值。典型是「当按下按键」被写成 RIGHT，而 Scratch 只认 right arrow —— 那块积木就永远不会触发。
  • 真写出菜单里没有的值时，工具会明确报一条警告并列出可用取值，不再默默「写入成功」。

AI 现在知道自己在哪个版本

  • xce_read_env 会报当前版本、许可（GPL-3.0-only）和官方页地址。你问「我这是哪一版 / 什么许可 / 官网在哪」，它会去查，而不是凭记忆答。
  • 提示词里注入的日期明确标注为 UTC 日期，并说明它不是本地时间；要报时间或日期时它会先调 xce_get_time，不再把 UTC 当成你的本地时间。

桌面版换了安装器

  • 安装包从 NSIS 换成 Inno Setup，欢迎页做了主题化。你在旧版上选的安装目录会被自动带上、不用重选，也不会动你的应用数据。

其他

  • 隐私政策更新：新增「AI 功能」一节，说明对话与密钥只存在你的设备上、AI 请求直达你自己配置的服务商；云变量一段改成默认连 TurboWarp 的服务器。

4.3.0

2026-10-06

这一版把 AI 手里「图形」那一半补完整了：以前它只会往项目里添新东西，现在画过的能改、不要的能删、网上的图也能拿来用。

AI 能改它画过的、也能清理了

  • 就地编辑造型：AI 可以重画一个已有的矢量造型（比如把自己画歪的手改对），原来的样子会留着用于撤销。
  • 删除造型：不想要的造型 AI 能直接删掉（每个角色至少要留一个），删错可撤销。
  • 从网址导入图片：给 AI 一个图片链接（webp / png / jpeg / svg），它会下载下来当作新造型 —— webp 会自动转成 PNG。桌面版由应用自己下载，不受浏览器跨域限制；图片上限 10MB。
  • 重命名角色：AI 可以给角色改名，所有脚本照常工作；「XCEAGENT」这类保留名不能占用。
  • 删除便签：AI 留的注释（xce_note）现在也能按编号删掉，同样可撤销。
  • 新建角色的流程顺了一下：新角色先带一个空白造型，画造型是独立的下一步 —— AI 不会再在建角色那一步被图卡住。

导出文件知道自己是哪一版的

  • 配置（.output.xce）和对话记录（.chat.xce）导出时记下应用版本，导入时会告诉你是哪一版导的 —— 以后翻旧备份出了问题能一眼对上。
  • 两类文件拿错时（拿配置文件去导对话、或反过来）提示说得更明白，会直接告诉你该用哪一栏。

其他

  • AI 的参考文档库改叫 fastdocs 并扩充了内容（编辑器、虚舟实验室、扩展相关），「查资料」和「会做的事」在 AI 那边分得更清。
  • 提示词与实际能力对齐了几处（比如造型编辑），AI 描述自己能做什么时不再自相矛盾。

4.2.0

2026-10-05

AI 终端这一版补上了「长期陪你用」需要的几块：AI 会记事了、配置能搬走了、对话能导出了，还多了一批更好用的工具。

AI 会记事了

  • 长期记忆：跟 AI 说过的偏好、项目背景这类事实，它现在能自己存进记忆、下个会话自己想起来。平时只占一行索引，用到才细读，不白烧 token。
  • 项目级记忆与角色：项目里放一条 XCEAGENT 注释，AI 打开项目就知道这个项目是谁的、该按什么习惯来；项目自己的备忘（XCEMEMORY）也能存取。
  • 用户自定义技能：在设置里可以自己写参考文档（skill），AI 和内置技能一样能读到。

配置和对话能搬走了

  • 配置导出 / 导入（.output.xce）：API 密钥、自定义供应商、提示词、记忆、技能一键打包带走，换台机器导入即用（默认包含密钥，也可以勾掉；导出页有明确警示）。
  • 对话记录导出 / 合并导入（.chat.xce）：单条对话或整个会话库都能导出备份；导入时和本地冲突的记录可以三选一处理，不会把已有的覆盖掉。

工具箱扩了一轮

  • 按 id 改脚本：AI 读出脚本时带编号，可以精确替换、删除某一段，还能撤销（undo 支持编辑操作）。
  • 触发事件：AI 可以直接拉广播、点绿旗、触发角色点击，不用再教你怎么点。
  • 修改上一轮发言：说错的话可以改掉重答，改动点之后还能分叉出新对话。
  • 随手笔记（xce_note）：AI 能往项目里留便签，下次接着干。
  • 提问有超时了：AI 向你提问（xce_ask_user）60 秒没动静会自动标「超时未回答」，不会干等；你在别的窗口忙它也不会傻卡。

更看得清、叫得回

  • Token 用量统计：每轮回复脚注显示本次输入（含缓存）/ 输出、生成速度，上下文栏还能看到缓存命中率。
  • 桌面通知：AI 干完一轮、或者有事要你拿主意时弹系统通知把人叫回来；窗口开着的时候不会烦你。网页版也会在第一次发送时申请通知权限。
  • 舞台后台渲染失败会说明原因（网页版切到后台标签页时），并提示你可以让 AI 发通知叫你回来。

界面

  • AI 面板大改版：多会话管理、思考默认折叠、往上翻历史时不被强行拉回底部、设置就地可改。
  • 多供应商接入优化，模型协议兼容性修复若干。

4.0.4

2026-10-04

AI 现在能自己建角色、自己画造型

  • 新建角色：跟 AI 说「加一个红色的气球角色」，它会自己建一个角色，并画一张矢量图给它当造型 —— 这是 AI 第一次能交给你图形，而不只是积木。
  • 给已有角色补造型：同一个角色想要第二套造型（走路、跳跃、受伤），也让 AI 画。
  • AI 会先回看自己画的东西再交差：造型画完渲染成图给它看一眼，不会闭着眼睛说「画好了」。看得见图的是视觉模型；文字模型会直说看不到，不会编。
  • 它手里多了一本画图的手册（只支持一部分 SVG 写法、尺寸必须写成数字、旋转中心在画布正中），动手前先读，而不是画完才发现一片空白。
  • 边界说清了：AI 只新增，不动你已有的角色和造型；也没有删角色、删造型的工具。

画出来的角色不会丢

  • 自动保存会连图形一起存：以前快照里只有积木、没有矢量图，AI 画的造型刷新一下就变空白。现在刷新、重开项目都还在。
  • 一轮干完那行「本轮变更」现在也会报角色和造型（比如「红气球 新角色」），「回退本轮变更」同样认得这两种改动。

供应商多了，自己也能加

  • 预设供应商从 10 家扩到 23 家：OpenAI、Anthropic Claude、Google Gemini、xAI Grok、Mistral、智谱 GLM、Kimi、通义千问、豆包、混元、文心、MiniMax、讯飞星火、阶跃星辰、Groq、OpenRouter、硅基流动、Together、Fireworks、Cerebras、DeepInfra、本地 Ollama 等。设置页的下拉按「国内 / 国外 / 聚合与云 / 本地」分了组，翻起来快多了。
  • 支持 Anthropic（Claude）官方协议：除了原来的 OpenAI 兼容端点，现在也能直连 /v1/messages。开着思考的 Claude 在调用完工具之后能接着往下写，不会被接口拒掉。
  • 可以自己加供应商，而且能加多条：名字、协议、地址、非标准路径都自己填，填完点「拉取模型列表」就把那家的模型拉回来，和预设的用起来一样。

换供应商不用重贴密钥

  • 密钥按供应商分开存：以前只有一个位置，切到别家就会把上一家的 key 顶掉，切回来还得重贴；现在每家一把，来回切自动对上。
  • 4.0.3 及更早存在设置里的那个 key 会自动搬进新的密钥表，不用重填。

修复

  • 桌面版窗口能正常关掉了：桌面版的窗口之前有几率点右上角的叉完全没反应、也没有任何提示 —— 项目一有没保存的改动就是这样。原因是编辑器自带的「离开前确认」在网页上会弹提示、在桌面版里却什么都不弹，直接把关闭请求咽掉了。现在改成弹自家的对话框问一句「确定要退出吗」，点「退出」才关；没有未保存改动时照旧一次关掉。顺便这套对话框是全站统一的（浅色、中性阴影、响应很快），以后别的地方要用同一套。
  • 严格网关不再报 400：下发工具声明时少写了一个参数名，宽松的供应商照收不误，严格的网关直接回「缺少 parameters」，一整轮都跑不起来。现已修正。
  • AI 写的裸链接不再把紧跟其后的中文标点一起吞进去（之前从那种链接复制出来是一长串 %E5）。

4.0.3

2026-10-04

面板更简单，常用设置就地能改

  • AI 面板瘦身：头部不再写标题，只留一个状态点和几个图标按钮，省下的宽度都给内容。
  • 换模型不用进设置页：点输入区那行的模型名，就地打开面板挑模型、调思考强度，点一下立刻生效（从下一轮开始用）。密钥、上下文限额、提示词还在面板底部的「更多设置」里。
  • 发送 / 停止换成两个图标按钮，输入区那一行不再挤文字。

看得见它在想什么、动过什么

  • 思考行带秒数：思考的时候显示「思考中 · 12s」，说完定稿成「思考过程 · 共 13s」。
  • 每轮变更 + 一键回退：一轮干完，答复下面多一行「本轮变更」，写明哪个角色多 / 少了几块积木；旁边可以「回退本轮变更」，把这一轮的改动整批收回去（会先问一次再动手）。
  • 删脚本也能撤销：删除之前先留一份原样快照，删错了能摆回来。
  • 工具输出在干活期间自动摊开，整轮结束跟着收起；出错的一律摊开，不会藏起来。
  • 积木数目跟 Scratch 自带「积木数量」插件的口径一致，界面上的 +N / −M 和你自己数出来的对得上。
